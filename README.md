# Linux 安全分析工具集

一套专业的 Linux 系统安全分析工具，包含挖矿程序检测、进程深度分析和 SSH 日志分析三大功能。

## 📦 工具列表

### 1. ProcMinerHunter.sh - 深度挖矿程序检测工具
专业的挖矿程序检测工具，能够深度扫描系统中的挖矿程序，包括可执行文件、配置文件、代码、定时任务等各个层面。

### 2. ProcessAnalyzer.sh - 专业进程分析工具
全面的进程信息分析工具，可以深入分析指定进程的详细信息，包括源文件、启动链、网络、CPU、文件等。

### 3. ssh_log.sh - SSH 登录日志分析工具
强大的 SSH 登录日志分析工具，支持自动识别系统，统计 SSH 登录成功/失败次数，分析爆破 IP 来源。

8. **深度网络连接扫描**
   - 检查已知挖矿端口（3333、4444、5555 等）

   - 显示连接详情

9. **全面启动脚本扫描**
   - Systemd 服务扫描
   - SysV init 脚本扫描
   - Upstart 任务扫描
   - Shell 配置文件扫描
   - 桌面环境启动扫描
   - SSH 启动脚本扫描

   - xinit 启动扫描
   - 网络启动配置扫描

    - 扫描系统日志中的挖矿活动
    - 显示相关日志内容

## 📋 常见问题

### ProcMinerHunter.sh

**Q: 扫描结果为空怎么办？**
A: 可能是系统确实没有挖矿程序，这是正常情况。建议定期运行进行监控。

**Q: 发现可疑进程后如何处理？**
A: 
1. 使用 `kill -9 <PID>` 终止进程
2. 删除可疑文件
3. 检查定时任务和启动项
4. 更改所有密码

**Q: 为什么需要 root 权限？**
A: 某些扫描模块（如定时任务、用户 crontab）需要 root 权限才能访问。

### ProcessAnalyzer.sh

**Q: 如何找到要分析的进程 PID？**
A: 可以使用以下命令：
```bash
ps aux | grep <进程名>
pgrep <进程名>
pidof <进程名>
```

**Q: 分析结果中的风险等级是什么意思？**
A: 
- 安全：未发现可疑特征
- 低危：发现少量需要注意的特征
- 中危：发现一些可疑特征
- 高危：发现多个可疑特征，建议立即处理

**Q: 可以分析内核进程吗？**
A: 可以，但内核进程通常没有可执行文件链接，某些信息可能无法获取。

### ssh_log.sh

**Q: 脚本提示"不支持或未识别的 Linux 发行版"怎么办？**
A: 请确认您的系统是基于 systemd 的主流发行版。如果是其他发行版（如 Arch Linux），可能需要手动修改脚本中的日志路径配置。

**Q: 为什么统计结果为 0？**
A: 可能的原因：
1. 指定日期没有 SSH 登录记录
2. SSH 服务未运行
3. 日志轮转导致数据不在主日志文件中
4. 日期格式不匹配（建议使用 YYYY-MM-DD 格式）

**Q: 如何分析压缩的旧日志？**
A: 当前版本只分析未压缩的日志文件。如需分析 `.gz` 压缩的日志，可以使用以下命令解压：
```bash
sudo gunzip /var/log/auth.log.1.gz  # Ubuntu/Debian
sudo gunzip /var/log/secure.1.gz   # CentOS/RHEL
```
